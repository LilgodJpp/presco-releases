# PRESCO — installateurs

Ce dépôt ne contient que les **installateurs** du logiciel PRESCO (Windows et macOS) et le fichier
`latest.json` lu par les logiciels installés pour se mettre à jour. Le code source est privé.

Chaque mise à jour est signée : un logiciel PRESCO installé refuse tout fichier qui n'est pas signé
par la clé de PRESCO.

## Installer
Télécharger la dernière version dans **Releases** :
- **Windows** : `PRESCO_x.y.z_x64-setup.exe`. Si Windows affiche « Windows a protégé votre ordinateur »,
  cliquer « Informations complémentaires », puis « Exécuter quand même ».
- **macOS** : `PRESCO_x.y.z_universal.dmg`. Au premier lancement : clic droit sur l'application, puis « Ouvrir ».
